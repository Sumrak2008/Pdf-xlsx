# PdfXlsx

A fully offline Windows 10/11 (x64) desktop application that converts PDF
documents into editable `.xlsx` workbooks — real Excel cells, not images.
Runs entirely from a portable, unzip-and-run folder: no installer, no admin
rights, no network access at runtime.
