# PdfXlsx — преобразование PDF в редактируемый Excel

Полностью офлайн-программа для Windows 10/11 (x64), которая превращает PDF-документы
в редактируемые файлы XLSX: таблицы становятся настоящими ячейками Excel, а не
картинками.

Программа никогда не обращается к сети Интернет, не запускает никаких серверов и
не отправляет никаких данных за пределы вашего компьютера. Подробности — в
[SECURITY_OFFLINE.md](SECURITY_OFFLINE.md).

## Возможности

- Перетаскивание PDF-файлов прямо в окно программы (drag-and-drop), пакетная
  обработка нескольких файлов за один запуск.
- Автоматическое определение типа каждой страницы: обычный текстовый PDF,
  отсканированное изображение или смешанный документ — и выбор подходящего
  способа извлечения для каждой страницы отдельно.
- Прямое извлечение текста и таблиц из текстовых PDF (без OCR, без потери
  точности) там, где это возможно; распознавание текста (OCR) — там, где
  страница представляет собой изображение.
- Поддержка русского, английского и смешанного русско-английского текста.
- Автоматическое определение и исправление поворота страниц — как
  зафиксированного в самом PDF, так и «вшитого» в пиксели отсканированного
  изображения.
- Таблицы с границами и без границ, объединённые ячейки заголовков,
  многостраничные документы, документы с пустыми страницами.
- Ячейки, в значении которых программа не уверена, подсвечиваются жёлтым
  цветом и получают комментарий на русском языке с указанием причины.
- Программа никогда не придумывает символы, не «исправляет» коды и номера
  и не убирает ведущие нули — при малейшей неоднозначности значение
  сохраняется как текст.
- К каждому результату прилагается отчёт о преобразовании (.txt), в котором
  *нет* распознанного текста или значений ячеек — только статистика,
  предупреждения и список использованных механизмов обработки.

## Системные требования

- Windows 10 или Windows 11, 64-разрядная версия.
- Не требуется: Python, Java, Microsoft Office, права администратора,
  подключение к Интернету.
- Программа поставляется в виде папки («портативная» сборка) — установка не
  нужна, достаточно распаковать ZIP-архив и запустить `PdfXlsx.exe`.

## Быстрый старт

1. Скачайте файл `PdfXlsx-<версия>-windows-x64.zip` со страницы релизов
   репозитория и сверьте его контрольную сумму SHA-256 (файл
   `<имя_архива>.sha256` лежит рядом).
2. Распакуйте архив в любую папку, в которую у вас есть права на запись
   (рабочий стол, «Документы» и т.п.). Права администратора не нужны.
3. Запустите `PdfXlsx.exe` внутри распакованной папки.
4. Перетащите один или несколько PDF-файлов в список или нажмите «Добавить
   файлы…».
5. При необходимости настройте параметры преобразования (см. ниже).
6. Нажмите «Начать преобразование».
7. После завершения нажмите «Открыть папку с результатом», чтобы увидеть
   готовые файлы.

**Важно:** не удаляйте и не перемещайте папку `tools` внутри распакованной
программы — там находится встроенный движок распознавания текста (OCR).
Без неё распознавание сканов работать не будет.

## Параметры преобразования

| Параметр | Назначение |
|---|---|
| Язык распознавания (OCR) | Русский / Английский / Русский + английский — выбирайте в зависимости от языка документов. Не влияет на страницы, читаемые напрямую из текста PDF. |
| Подсвечивать ячейки, требующие проверки | Включает жёлтую подсветку и комментарии для неуверенно распознанных или неоднозначных значений. |
| Порог уверенности OCR | Слова и ячейки, распознанные с уверенностью ниже этого порога (0–100%), помечаются как требующие проверки. |
| Отдельный лист на каждую страницу / Отдельный лист на каждую таблицу | Определяет, как таблицы распределяются по листам итоговой книги Excel. Если включено «на каждую таблицу» — оно имеет приоритет. |
| Сохранять отчёт о преобразовании (.txt) | Создавать ли рядом с результатом файл `<имя>_conversion_report.txt`. |
| Папка сохранения результата | Куда сохранять результат; по умолчанию — рядом с исходным PDF-файлом. |

## Результат

Для каждого обработанного файла `<имя>.pdf` создаются:

- **`<имя>_editable.xlsx`** — книга Excel с редактируемыми ячейками,
  сохранённым форматированием чисел/дат, объединёнными ячейками заголовков
  и подсветкой неуверенных значений.
- **`<имя>_conversion_report.txt`** — отчёт о преобразовании: количество
  страниц и таблиц, использованные методы обработки, число ячеек,
  потребовавших проверки, предупреждения и ошибки по отдельным страницам.
  Отчёт **не** содержит распознанного текста документа.

## Известные ограничения

Полный список — в [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md). Кратко:
на одной отсканированной странице распознаётся не более одной основной
таблицы; «живые» формулы Excel не восстанавливаются (сохраняется
рассчитанное значение); качество распознавания сильно зависит от качества
скана.
